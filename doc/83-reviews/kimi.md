  ## Q3 — Which fixes are NOT output-identical

  Bit-identity anatomy first (all code-verified):
  - **Emission order** = (match batch, window, `hi` cycle) via `by_hi` (:1060-1068) and expiry at :1260-1268. The diagnoses all cite tau; the admission boundary is the sharper hazard. Inert on dn_pred_cam (c3:61 "of which gate C 0/0", no "gate C null armed" line).

  ## Q5 — What the sibling records add (and what they don't)

  Transfers as-is (architecture-neutral, all verified against the sibling docs):

  - **PERF-ATTEMPT-1 (M17) is F04's exact failure mode, twice over**: order-dependent shared state (their valley splitting; ODIA's Gate C/admission/anchors) and *dropped emissions* from a missing tail flush (ODIA's deferred-`give` design must drain through the flush path :1287-1294; their batch-4096 bug was a dropped tail, not a race).
